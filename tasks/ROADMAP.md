Briefs for the phase in progress exist; later phases have none.

## Phase 2 — Lyrics Studio (T-201 … T-214) — **COMPLETE**, tagged `phase2-done` (2026-08-26) — [phase-2.md](phase-2.md)
Brief form with prefills, system-prompt assembly from profile (ARCHITECTURE §6), streaming generation UI, versioned editor with structure-tag validation, approve → handoff store action, consent-gated prompt optimizer with diff view (shared component — reused for audio tags in Phase 3).

**Milestone check (live):** brief → lyrics stream in → edit → approve; optimizer diff accept/revert round-trips.
**Done:** T-201 … T-210 (project/lyric store, brief + prompt assembly, the structure-tag lint, `reasoning_effort`, the streaming command, the frontend bridge/store, the brief form, the generation UI, the versioned editor with lint + approve, and the consent-gated prompt optimizer with the shared `<PromptDiff>`), plus T-211's live milestone and the fix-ups it produced (T-212 config persistence, T-213/T-214 three UI defects). **Milestone passed 2026-08-26** against a real Ollama: a whole song in 6.9-9.2 s with reasoning suppressed, the optimizer preserving its fixed lines 5/5, and the approved lyric on disk with its consent flag.
